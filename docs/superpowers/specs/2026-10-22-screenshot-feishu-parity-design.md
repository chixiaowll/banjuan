# 截图对标飞书 — 设计

日期：2026-10-22
状态：已与用户确认（架构 + A 框选手感 + B 标注工具 + C 输出动作）

## 背景与目标

桌面端已有区域截图（`app/src/main/screenshot-service.ts` + `renderer/views/ScreenshotOverlay.tsx`）：框选、矩形/箭头/画笔/文字、撤销、复制到剪贴板。与飞书截图相比的主要差距：

- **唤出慢**：每次截图新建窗口并加载 3.2MB 的主界面包；截图以 PNG data URL 传给 `<img>`（PNG 编码约 160ms）。
- **框选手感**：不能识别窗口、选区不能调整大小或移动、没有放大镜和尺寸提示。
- **标注**：只有 4 种工具，画完不能再选中、移动、删除或改样式，没有马赛克、序号、椭圆、荧光笔，没有重做。
- **输出**：只能复制；不能保存文件、钉图、插入笔记。
- **多显示器**：只截光标所在屏，打开后不能换屏。

目标：在保持现有稳定性措施的前提下补齐 A/B/C 三块，按下快捷键到看见浮层的时间目标约 300ms。

不在范围内（以后再做）：OCR、滚动长截图、录屏、翻译。

## 已有的稳定性约束（必须保留）

这些是此前修截图问题时踩出来的，新实现不能回退：

- 浮层窗口不透明（`backgroundColor` 黑色、非 transparent），置顶级别用 `'floating'`，不覆盖菜单栏、不接管所有桌面——任何故障都不能把用户困住。
- 窗口 `show: false`，渲染端确认画面已画出（两帧 rAF）后发 `ready` 再 `show`，杜绝黑屏闪烁；3 秒后无论如何显示，保证错误面板可见、Esc 可用。
- 渲染进程崩溃 / 无响应时收起浮层；`capturing` 标志在所有退出路径上复位。
- 选区外的暗色遮罩用 4 个矩形 div，不用全屏 clip-path 动画（会卡死 macOS 合成器）。
- 拖拽使用 pointer capture，拖出窗口松手也能收到 pointerup。
- 工具栏限制在显示器可用区域（避开菜单栏和 Dock）。
- 文字输入框打开时不能因为画布 mousedown 失焦。
- 默认快捷键 Ctrl+Shift+A（避开飞书的 ⌘⇧A），可在设置中修改，注册失败时保留原快捷键。

## 1. 架构与数据流

### 主进程：`src/main/screenshot/`

| 模块 | 职责 |
|---|---|
| `capture.ts` | 按光标所在屏的原生尺寸 `desktopCapturer.getSources`，用 `toBitmap()` 取原始 BGRA 像素（省掉 PNG 编码）；并行获取窗口列表（macOS：JXA 调 `CGWindowListCopyWindowInfo`，约 50ms；其他平台返回空列表） |
| `overlay-window.ts` | **预热**：应用启动后创建一个隐藏的浮层窗口并加载截图入口；每次截图复用，结束时隐藏并通知渲染端重置，不销毁。截图时 `setBounds` 到目标屏 → 下发会话数据 → 等 `ready` → `show`。**跟随换屏**：渲染端报告"尚未选区"期间，每 50ms 检查光标所在屏，换屏时移动窗口并换图。崩溃时丢弃窗口，下次截图重建 |
| `outputs.ts` | 复制、保存文件、钉图（独立的置顶小窗口）、插入笔记（发给最近聚焦的主窗口） |
| `hotkey.ts` | 现有快捷键注册与回滚逻辑原样迁入 |
| `index.ts` | `initScreenshot` / `triggerCapture` / `disposeScreenshot`，对外接口不变 |

会话数据（main → overlay）：`{ sessionId, bitmap(Uint8Array BGRA), pixelWidth, pixelHeight, cssWidth, cssHeight, scaleFactor, workArea, windows: Rect[]（CSS px，前到后）, canInsertNote }`。

### 渲染端：独立入口 `screenshot.html`

Vite 多页面构建，新入口只打包 React 与 shared-ui 的 i18n 子模块，不加载主界面包。钉图窗口复用同一入口，用 hash `#pin` 区分。

| 模块 | 职责 |
|---|---|
| `Overlay.tsx` | 组合以下模块；会话开始 / 结束时重置全部状态 |
| `selection.ts` + `useSelection` | 选区状态机（纯函数，可单测） |
| `annotations/` | 标注数据模型、命中检测、绘制、撤销/重做（纯函数为主） |
| `Toolbar` / `StylePanel` / `Magnifier` | 工具栏、样式面板、放大镜 |
| `compose.ts` | 选区 + 标注合成 PNG（设备像素） |

背景用 `<canvas>` 直接 `putImageData`（BGRA→RGBA 转换），取代 `<img>` + data URL。

### 数据流

```
快捷键 / 按钮
  → capture：截屏位图 ∥ 窗口列表（并行）
  → overlay-window：预热窗口 setBounds + 下发会话数据
  → 渲染端画好 → ready → show（目标约 300ms 内可见）
  → 框选 / 标注
  → 完成：渲染端合成 PNG → outputs（复制 / 保存 / 钉图 / 插入笔记）
  → 隐藏并重置浮层
```

## 2. A — 框选手感

- **窗口识别**：浮层打开后，光标下最前面的窗口自动高亮（边框 + 尺寸标签）；单击（未拖动）即选中该窗口区域；拖拽则自由框选。
- **选区编辑**：8 个控制点调整大小，选区内拖动为移动（尚未标注时）；方向键微调 1px，Shift+方向键 10px（有选中的标注时，方向键移动标注）。
- **尺寸标签**：选区左上角外侧显示 `宽 × 高`（物理像素）。
- **放大镜**：拖拽 / 调整大小 / 悬停未选区时，光标旁显示 8 倍放大（像素网格 + 十字线）、坐标和颜色值；按 C 复制颜色 `#RRGGBB`。
- **Esc 逐级退出**：正在输入文字 → 结束输入；选中了标注 → 取消选中；有选区（未标注）→ 取消选区；否则退出截图。
- **右键**：有选区时取消选区，没有选区时退出截图。
- **双击选区 / 回车**：复制并退出。

选区状态机（纯函数）：`idle → hovering(window?) → dragging → selected ⇄ (resizing | moving)`，输入为指针 / 键盘事件，输出新状态；单元测试覆盖窗口点选、拖拽阈值、8 个控制点、边界钳制、键盘微调。

## 3. B — 标注工具

- **工具**：矩形、椭圆、箭头、画笔、荧光笔（半透明粗笔）、文字、马赛克（涂抹区域像素化，取自背景位图）、序号（①②③…自动递增，带圆底）。
- **样式**：6 种颜色、3 档粗细、3 档字号；记住上次选择（localStorage）。
- **编辑**：在"选择"状态下点中已有标注即选中（显示包围框）；拖动移动、Delete/Backspace 删除、样式面板修改选中标注的颜色和粗细；双击文字重新编辑。
- **撤销 / 重做**：⌘Z / ⇧⌘Z（Windows/Linux 用 Ctrl），对增删改都有效。
- 有标注后选区锁定（不能再改选区），避免标注错位——与现有行为一致。

数据模型：`Shape = { id, kind, style, ...几何 }`，统一的 `hitTest(shape, point)`、`bounds(shape)`、`translate(shape, dx, dy)`、`render(ctx, shape, scale, background)`；历史栈保存 shapes 快照。

## 4. C — 输出动作

工具栏右侧：撤销、重做 | 钉图、保存、插入笔记 | 取消、完成（复制）。

- **复制**：回车 / 双击选区 / 完成按钮；写入剪贴板后退出，主窗口提示"已复制"。
- **保存**：⌘S 或按钮，系统保存对话框，默认文件名 `截图 YYYY-MM-DD HHmmss.png`（按界面语言），默认目录"图片"。
- **钉图**：在原位置打开一个置顶的无边框小窗口显示截图；可拖动、滚轮缩放（10%–400%）、双击关闭；右键菜单：复制、保存、关闭。可同时钉多张。
- **插入笔记**：插到当前激活的笔记标签的光标处（作为图片附件保存并插入图片块）；当前没有打开的文本笔记时按钮禁用并提示原因。

## 5. 多显示器

- 截图时只截光标所在屏，浮层开在该屏。
- 尚未开始选区时，光标移到另一块屏：浮层跟过去并换成那块屏的截图（其他屏的截图在浮层显示后于后台补截并缓存）。
- 一旦开始选区，锁定在当前屏。

## 6. 错误处理

- 无屏幕录制权限：沿用现有引导对话框。
- 截屏失败 / 窗口列表获取失败：窗口列表失败时降级为无窗口识别；截屏失败时提示并复位。
- 渲染端异常：错误面板（可点击或 Esc 关闭），不留下置顶的空白层。
- 保存 / 插入失败：主窗口提示条显示原因。

## 7. 测试

- 纯函数单测（vitest）：选区状态机、命中检测 / 包围盒 / 平移、撤销重做、合成区域计算、BGRA→RGBA、序号递增、文件名格式。
- 主进程：输出动作（保存路径、文件名）与窗口生命周期（预热、复用、崩溃重建）用现有的 CDP 自动化脚本回归。
- 性能：测量快捷键触发到浮层 `show` 的耗时（主进程打点），目标约 300ms；与改造前对比。
- i18n：所有界面文字走 `t()`，7 种语言齐全。
