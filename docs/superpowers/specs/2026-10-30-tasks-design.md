# 任务（待办）与笔记历史版本界面 设计

日期：2026-10-30　分支：`feat/tasks`

## 目标

笔记里的复选框就是任务。人在 App 里打勾、程序（CC Desk 每晚的工作记录、Claude Code、内置助手）用命令行 / MCP 改，改的都是笔记里的同一个块；半卷只建索引、提供查询和改写，并给一个“待办”视图把所有没做完的事集中起来。顺带给笔记加“历史版本”面板（写入基建里已有版本数据，App 里还看不到）。

## 1. 什么是任务

- **任务 = Markdown 笔记里的 `checkListItem` 块**（含嵌套在其他块下的）。普通列表项（哪怕带任务链接，如日记里“挂起”的快照 `- 部署测试环境（已挂 3 天）[↗](banjuan://task/<id>)`）不是任务。脑图、手写笔记不在范围内。
- **ID**：块自带的隐藏 `id`，正文里不写任何东西。程序写入的复选框若没有 id，写入时补上；建索引时遇到没有 id 的（旧笔记），补上并写回一次。
- **Markdown 往返**：给 AI 的 Markdown（`note show --body`、`read_note`）里复选框行尾带 ` ^<id>`，写回时识别并还原，所以 AI 改写整节后任务 ID 不变。导出成文件的 Markdown 不带。
- **文字里的约定**（都可选）：
  - 截止日期 `📅 2026-11-05`；
  - 完成日期 `✅ 2026-10-28`（`task done` 时补上；在 App 里打勾时不改正文，完成时间只记在索引里）；
  - 优先级：文字以 `[P0]`（可加粗 `**[P0]**`）开头；
  - `#标签`：第一个标签作为所属项目。
- **所属项目**：`#标签` 优先；否则笔记所在文件夹的最后一级名称；顶层笔记为空。返回值同时带笔记所在文件夹的完整路径，具体怎么对应由调用方决定（不写死任何文件夹约定）。

## 2. 索引

- 新表 `tasks(id, note_id, text, done, due, priority, project, first_seen, done_at, position)`。
- 笔记新建 / 修改 / 删除 / 移动、从磁盘重扫、同步写入后，都重建该笔记的任务；打开书房时若索引版本落后，在后台全量重建。
- `first_seen`：第一次见到这个任务的时间，重建时保留（“已挂 N 天”由它算）。`done_at`：文字里有 `✅ 日期` 用它，否则为第一次见到它被勾上的时间。
- `text`：去掉优先级前缀、日期标记和行尾 id 的纯文字。

## 3. 操作（写入前都留历史版本，可带写入来源）

| 命令行 | MCP | 说明 |
|---|---|---|
| `task list [--open\|--done] [--project <名>] [--due-before <日期>] [--done-since <日期>] [--note <id>] --json` | `list_tasks` | 返回 `[{id, text, done, due, priority, project, note:{id,title,folder}, link, firstSeen, doneAt}]`；`--project` 按项目名精确匹配（忽略大小写） |
| `task add "<内容>" --note <id> [--section "### 待办"] [--due <日期>] [--priority P0] --json` | `add_task` | 追加到笔记（指定小节末尾，小节不存在就在文末新建）；返回 `{id, link}` |
| `task done <id> [--comment "<结果>"] --json` | `complete_task` | 勾上、文字末尾补 `✅ 日期`；评论作为任务下的一段 |
| `task update <id> [--text] [--due] [--priority] [--move-to <note-id> [--section]] --json` | `update_task` | 移动时任务 ID 不变 |

- `banjuan://task/<id>` 链接：打开所在笔记并滚动到那一行、短暂高亮。

## 4. 界面（沿用现有风格，七种语言）

- **侧栏“待办”**：未完成任务按项目分组；筛选：全部 / 今天到期 / 逾期 / 本周 / 按项目；逾期标红；每行显示“已挂 N 天”。点复选框完成（写回原笔记），点文字跳到原笔记那一行。可切换“显示已完成（最近 7 天）”。
- **笔记里的任务链接**：显示任务当前状态（完成后加删除线）。
- **笔记“历史版本”面板**：笔记工具栏加按钮，列出版本（时间、谁写的、为何留下、开头文字），可预览、可恢复（恢复本身也可撤销）。

## 测试

- 单测：任务解析（日期 / 优先级 / 标签 / 嵌套）；索引（新建、改文字 ID 不变、勾选、删除、移动、first_seen 保留）；Markdown 往返保留任务 ID；add / done / update / move。
- 实测：App 里勾掉一个任务，`task list --open` 立刻少一条；`task done` 后 App 里的复选框同步打勾；改了任务文字后 ID 不变、链接仍能跳到那一行；没有复选框的笔记不受影响；待办视图筛选、历史面板恢复。
